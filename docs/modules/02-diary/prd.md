# 万事历日历双入口与日记 PRD V0.1

## 1. 需求目标

用户点击日历里的任意日期后，可以直接选择「创建日程」或「写日记」。日程用来安排事项，日记用来记录当天实际发生的事。两条路径都从所选日期开始，方便已有日历用户随手记录和回看。

## 2. 页面与交互

| 操作 | 页面行为 |
| --- | --- |
| 点击日期 | 打开现有的「当天事项」面板，顶部显示日期，中间展示当天已有日程。将底部的「添加事项」替换成并排的「创建日程」和「写日记」。当天没有日程时，两个按钮仍可用。 |
| 点击「创建日程」 | 打开现有的「选择创建方式」弹框，保留「手动创建」和「AI 语音或文字」两个选项。手动创建表单默认带入所选日期，沿用原有的类型、循环和保存流程。 |
| 点击「写日记」 | 进入独立的日记编辑页，顶部显示所选日期，正文可直接输入。该日已有日记时，按钮显示「查看日记」，进入已有内容后可编辑。 |
| 返回或保存 | 返回原来选中的日期。保存成功后，日期面板显示「查看日记」，方便再次打开。编辑后未保存便返回时，提示「继续编辑」或「放弃修改」。 |

## 3. 日记编辑页

- **手动写日记**。用户可直接输入或编辑正文，正文为空时不可保存。
- **引用当天日程**。通过「添加日程」从该日期的已有日程中手动选择，在日记里显示事项名称。
- **一句话写日记**。用户输入几句口语，AI 生成可编辑的草稿。默认使用从日历带入的日期。若用户明确提到另一个日期，界面提示确认日期后再写入对应的日记。
- **AI 润色**。用户主动点击后才提交选中的日记内容。AI 整理句子和段落，保留用户表达的事实与情绪。用户确认采用后，结果进入编辑器，再由用户保存。失败时原文保留，可继续手动编辑。

## 4. 功能验收

- [ ] 点击一个有日程或无日程的日期，都能看到两个入口。
- [ ] 选择一个过去日期并点「创建日程」，先打开「选择创建方式」。再点「手动创建」，表单默认带入所选日期。
- [ ] 同一天点「写日记」，编辑页显示正确日期。保存后返回该日，再进入能看到原内容。
- [ ] 引用当天的「面试」日程后，日记中显示该事项名称。
- [ ] AI 草稿可编辑，采用前不会覆盖原文。日期不一致时，需要先确认日期。
- [ ] 刷新后，已保存的日记依然可以从对应日期打开。
