# 万事历 MVP PRD
V0.2 · 2026-11-18 · 方案评审

## 1. 目标与范围

帮助有日常记录和月底核对需要的用户，在一张日历记录事项，月末自动查看每个事项、各类型实际发生了多少天。

核心流程：选日 → 创建与循环 → 每日确认 → 月末天数 → 明细核对 → 修改后重算。

本期：月历、正计时/倒数日/生日、循环、实际记录、编辑删除、月度统计、本地保存。原型扩展模块包括经期独立记录、AI漏记询问与全局/单事项分析范围设置，沿用既有Issue 04、06、07；基础闭环先实施。登录、云同步、多人和导出暂缓。

## 2. 竞品到产品的转化

| 来源 | 判断 | 功能 |
| --- | --- | --- |
| Google Calendar重复事件 | 成熟周期无需重新发明 | 类型与循环分开设置 |
| TimeTree日历筛选 | 多项内容先保证可读 | 同日多项列表、类型文字与图标 |
| TickTick月度打卡 | 月度统计已有竞品实现 | 明确实际天数、去重与明细核对 |
| Daylio快速活动记录 | 降低重复输入 | 名称复用、当天确认、备注选填 |
| Habitify连续记录 | 时间跨度与实际记录不同 | 正计时天数与月度发生天数分开 |
| YouLoft农历假期 | 本地化影响规则准确性 | 农历生日及中国假调休工作日 |

来源与分析见[竞品研究](../../research.md)。

## 3. 月历与当天事项

默认当前月，周一为周首；支持切月、返回今天。点日期打开当天多项列表，新增带入所选日；关闭面板保留月份与选中日。

### 批注

- [交互][改动] 日期入口：打开对应日；今天与选中日分别标记。
- [状态] 无事项：线性日历图标、“这一天还没有事项”、添加按钮。
- [规则] 计划生成不等于实际发生，不自动计入发生天数。

## 4. 创建、循环与保存

| 类型 | 必需信息 | 显示与限制 |
| --- | --- | --- |
| 正计时 | 名称、起始日、循环 | 已经过天数；可选持续天数或不结束 |
| 倒数日 | 名称、目标日、循环 | 剩余天数，到期日显示“就是今天” |
| 生日 | 名称、生日、公历/农历 | 固定每年，隐藏持续天数 |

循环支持仅一次、每日、每周、每月、每年、仅工作日、仅周末。每周可选多个星期；生日固定每年；工作日依据中国假调休表，周末指周六/周日。

### 批注

- [校验] 名称去首尾空白后必填；为空字段下提示并聚焦，保留输入。
- [状态] 保存中禁用重复提交；失败保留表单并可重试。
- [交互] 成功回原选中日并更新列表；有未保存修改时返回需确认。
- [异常] 缺年份假调休数据时说明无法准确生成，禁止静默当作周一至周五。

## 5. 记录、编辑与删除

当天状态为已发生、未发生、未记录；未操作保持未记录。同事项同日重复确认只保留一条有效记录。

详情进入编辑。循环编辑/删除先选作用范围，候选“仅这一次/整个系列”，确认前显示对历史记录的影响；取消不变更。最终历史处理策略见第8章。

## 6. 月末天数汇总

默认当前月，可切月。展示每事项、各类型实际发生天数及未记录日期；点合计进入日期明细并可修改原记录。

| 指标 | 口径 | 例子 |
| --- | --- | --- |
| 某事项天数 | 该事项当月已发生日期去重 | 阅读1日、3日发生=2天 |
| 某类型天数 | 该类型任一事项已发生日期去重 | 同日阅读、运动均正计时=该类型1天 |
| 全月已发生天数 | 全部已发生日期并集 | 同日多事项仍为1天 |
| 未记录日期 | 截至今天有计划但未确认的日期 | 未来与无计划日期不算漏记 |

正计时跨度、倒数天数与发生统计分开展示；生日出现也需确认后才计发生。合计由原始记录动态重算，修改、补录、删除后同步更新。

## 8. 待确认与验证

正计时起始第0/1天；倒数到期后行为；农历闰月、每月29/30/31日与2月29日处理；系列修改及历史保留；假调休来源与更新；用户是否更需要自定义标签统计。

AI全局默认关闭、单事项可排除，候选需用户确认；不自动覆盖记录，不做健康推断。统计口径是本轮可评审方案，待体验验证。
