# 万事历｜月历与当天事项 PRD

文档状态：草稿
所属模块：Issue 01 月历与当天事项
版本：V0.1

## 1. 用户场景与目标

用户打开万事历，查看某一天有哪些事项，
并从日期入口快速查看或新增事项。

本模块帮助用户看清事项在日期上的分布，
并支持同一天查看多个事项。

## 2. 本次范围

- 默认展示当前月份。
- 支持切换上个月、下个月和返回今天。
- 点击日期，打开当天事项面板。
- 同一天允许存在多个事项。
- 当天没有事项时，展示空态提示和新增入口。

## 3. 原型页面

| 页面编号 | 页面名称 |
|---|---|
| 01-01 | 月历·有记录 |
| 01-02 | 月历·空态 |
| 01-03 | 当天事项·多项 |
| 01-04 | 当天事项·空态 |

## 4. 核心操作流程

打开月历 → 选择日期 → 查看当天事项 → 关闭面板。

当天没有事项时：
选择日期 → 查看空态 → 点击新增事项入口。

## 5. 业务与交互规则

- 选中日期需要有明确的视觉标记。
- 事项状态通过文字或图标辅助表达。
- 当天事项面板展示所选日期。
- 关闭面板后，保留当前查看月份和选中日期。
- 新增事项的表单与保存规则在新增事项模块中定义。

## 6. 待确认事项

- 日期格中事项标记的数量与溢出展示方式。
- 同一天多个事项的默认排序规则。
