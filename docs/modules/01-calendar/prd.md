## 1. 目标与本期范围

用户在日历记录日常事项和重要日期，月末查看每事项、各类型实际发生的天数，并返回日期明细核对。借鉴竞品的重复事件、快速记录与月度回顾，计划与实际记录分开。[竞品依据](../../research.md)。

本版先跑通“选日 → 新建 → 类型与循环 → 保存 → 详情 → 修改或删除”。每日确认、月度统计与本地保存属于MVP后续实现；经期独立记录、AI漏记询问与全局/单事项分析范围沿用原04、06、07模块。登录、云同步、多人和导出暂缓。

## 2. 月历与当天事项

| 动作 | 产品行为 |
| --- | --- |
| 打开日历 | 默认当前月，周一为周首，区分今天与选中日 |
| 切月、回今天 | 更新月份；回今天同时选中今天 |
| 点击日期 | 展示该日多项列表；关闭面板保留选中日 |
| 点击添加或加号 | 进入新建，带入所选日期 |
| 该日无事项 | 展示线性日历图形、提示和添加入口 |

## 3. 新建与循环

| 类型 | 日期与展示 | 配置 |
| --- | --- | --- |
| 正计时 | 从起始日累计天数 | 持续天数或不设结束 |
| 倒数日 | 距目标日的天数，到期显示“就是今天” | 目标日与循环 |
| 生日 | 公历或农历生日 | 每年重复，隐藏持续天数 |

名称去首尾空白后必填，备注选填。循环支持仅一次、每天、每周多选、每月、每年、仅工作日、仅周末；类型与循环分别设置。工作日使用中国假调休表，周末指周六与周日。缺少年份数据时明确提示，不能静默按周一至周五生成。

| 动作 | 产品行为 |
| --- | --- |
| 名称为空时保存 | 字段下提示“请填写事项名称”，保留其他内容 |
| 正常保存 | 保存中防重复提交，成功返回原日期并更新列表 |
| 保存失败 | 保留表单和旧数据，允许重试 |
| 返回或取消 | 有未保存修改时询问；可继续编辑或放弃 |

## 4. 详情、编辑与删除

详情显示类型、日期、循环、结束条件、AI范围和备注。当天确认支持已发生、未发生、未记录；没有操作保持未记录，同事项同日仅一条有效记录。

| 动作 | 产品行为 |
| --- | --- |
| 点击事项 | 打开详情，编辑入口读取当前配置 |
| 保存循环修改 | 确认作用范围；原型候选为“仅这一次 / 这次及之后” |
| 删除循环事项 | 确认作用范围；原型候选为“仅这一次 / 整个系列” |
| 取消删除 | 返回详情，不变更事项 |
| 确认删除 | 更新所选范围和当天列表，其他事项保留 |

## 5. 月末天数

月度页按事项、类型展示实际发生天数，点合计进入日期明细。计划生成、正计时跨度与倒数天数都不直接计入实际发生。

| 指标 | 口径 |
| --- | --- |
| 某事项天数 | 该事项当月已发生日期去重 |
| 某类型天数 | 该类型任一事项已发生日期的并集 |
| 全月天数 | 全部已发生日期并集，各类型不能直接相加 |
| 未记录日期 | 截至今天有计划但未确认，排除未来和无计划日期 |

修改、补录或删除原记录后重算；同日阅读和运动各记1天，若同为正计时，该类型仍为1天。

## 6. 本版改动与待确认

新增：创建、循环子层、详情、编辑、删除及异常状态；改动：月历新增入口接通，原型与文档建立对应批注。交互演示采用预设数据，真实保存与统计待实现。

待确认：起始第0/1天、倒数到期后行为、特殊月日与农历闰月、系列修改对历史的影响、假调休来源。AI全局默认关闭，单事项可排除，建议经确认后才写入；经期不与纪念日共用普通正计时规则。
