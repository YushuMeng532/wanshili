# 万事历 MVP PRD
版本：V0.5 · 确认日期：2026-11-19

关联：[PRD](./prd.md)、[开发说明](./dev-spec.md)、[页面设计](./page-design.md)、[原型](./prototype.md)、[验证记录](./validation.md)。

## 1. 目标与本期范围

保留现有蓝粉绿前端设计，支持纪念日正计时、倒数日、公历生日、循环、修改删除和月度统计。产品前端使用当前浏览器本地保存；工作台用于查看页面与规则对应关系。当前规则以本版为准，取代V0.4的每日手动确认、正计时持续次数及系列范围待确认描述。

经期记录另属后续模块。本版不接入农历、法定假调休数据、AI服务、登录或云同步。

## 2. 月历与当天事项

周一为周首，打开当前月，区分今天与选中日；支持切月和回今天。点击日期展示当天面板，关闭后保留选中日。新建事项带入选中日期。

| 类型 | 日历标记 | 选中日期下方的事项 |
| --- | --- | --- |
| 正计时 | 进行中只标记开始日。结束后标记开始日和结束日，同一天只标记一次 | 从开始日至结束日按选中日累计。选中结束日显示「已结束 · 共 N 天」，结束日之后不再展示 |
| 倒数日 | 只在对应目标日倒数归零时标记 | 其他选中日期也展示倒数；目标日前显示还有N天，目标日显示就是今天，目标日后显示已过N天 |
| 公历生日 | 在对应生日日期标记 | 该日期展示生日事项 |

天数统一跟随选中日期，不固定以真实今天计算。日历标记与下方列表分别计算，列表有事项不代表该日一定有标记。

公历2月29日不生成事项和计划实例，其余闰年日期正常。自然日差值仍按真实公历计算。

## 3. 新建与循环

名称去首尾空白后必填，备注选填。正计时用于纪念日，新建时只选开始日期。进行中可从事项详情手动结束。生日默认每年重复，当前只提供公历有效保存；农历明确标记暂未接入。

倒数日可选择仅一次、每天、每周、每月、每年、仅工作日、仅周末。每周至少选一天；每月日期不足时按该月最后一天生成；29、30、31日均适用。若回退结果落在2月29日，跳过该次。每年2月29日同样跳过。工作日选项提示调休日历未接入，不能用周一至周五代算。

循环的持续次数按有效计划出现次数计算；月末回退算1次，跳过2月29日不占次数。仅一次的计划出现次数固定为1。正计时不提供这个选项，其自然日累计不受次数控制。

| 动作 | 行为 |
| --- | --- |
| 子层选择后点完成 | 仅更新主表单草稿 |
| 子层取消或关闭 | 保留打开子层前的值 |
| 主表单未点保存 | 不修改原事项 |
| 空名称保存 | 显示错误边框和请填写事项名称，保留其他填写内容 |
| 保存中 | 显示保存中并拒绝重复提交 |
| 保存失败 | 保留草稿与原事项，允许重试 |
| 取消有改动的表单 | 提供继续编辑和放弃修改 |

### 普通日程（新增需求，待实现）

普通日程适用于上课、例会等按计划发生的事项。新建事项的类型栏增加「普通日程」。名称必填，日期默认带入月历选中日，备注选填。循环默认「仅一次」，可改为每天、每周、每月、每年或仅周末。工作日选项沿用调休日历未接入的提示。选择循环后可设持续次数，按有效计划出现次数计算。选「仅一次」时固定为 1 次。

| 用户动作 | 产品行为 |
| --- | --- |
| 保存普通日程 | 在计划发生的日期标记月历，并在选中这些日期时显示当天事项。列表只显示事项信息，不显示正计时或倒数。 |
| 查看过去日期 | 已过去的计划自动计为已发生，计入所属月份。全月合计仍按日期去重。 |
| 修改或删除 | 支持「仅这一次」「这次及之后」「整个系列」，沿用现有范围规则并保留过去日程。非循环日程只有一个计划实例。 |

## 4. 详情、编辑与删除

详情展示类型、日期、天数或循环、AI开关与备注。移除所有由用户选择已发生、未发生、未记录的按钮。日期早于真实今天的日程统一为已发生；今天在进入次日后自动计入。原先的未发生选择不再参与新版本判断。

从开始日期的第二天起，已创建事项不可更改类型；界面显示不可用说明。其余字段仍可通过保存和范围选择更新。已有历史分段中的开始日期同样参与类型锁定，不能通过改日期绕过限制。

| 范围 | 修改 | 删除 |
| --- | --- | --- |
| 仅这一次 | 覆盖选中日的单次配置 | 只取消选中日计划 |
| 这次及之后 | 覆盖选中日起的未过去计划 | 取消选中日起的未过去计划 |
| 整个系列 | 覆盖全部未过去计划 | 取消全部未过去计划 |

三个范围适用于编辑和删除，选择后还需点确认保存或确认删除。取消不写数据。

过去日期的日程始终保留并可继续查看，任何范围都不移除历史；当选中日已过去，仅这一次不可执行，其他范围从今天开始生效。非循环事项按独立事件处理，同样保留过去历史。

### 手动结束正计时

| 操作或状态 | 产品行为 |
| --- | --- |
| 查看今天正在进行的正计时 | 从今天的事项列表打开详情，显示「结束正计时」次级操作。查看其他日期、尚未开始或已结束的事项时不显示该入口。 |
| 点击「结束正计时」 | 打开确认弹层，显示设备本地的当天日期及最终天数，并提示「结束当天计入天数，历史记录会保留。」 |
| 取消或关闭弹层 | 返回原详情，继续计时。 |
| 点击「确认结束」 | 将设备本地的当天日期记为结束日，返回已结束的事项详情。结束是独立操作，无需选择编辑或删除范围。 |
| 查看已结束的详情 | 显示「已结束 · 共 N 天」、开始日期、结束日期和备注。历史日期下方仍显示选中日对应的第 N 天。 |

开始日和结束日均计入最终天数。以 11 月 17 日开始、11 月 23 日结束为例，最终为 7 天。同一天开始并结束为 1 天。结束操作保留历史记录，结束日之后不再累计。原型链接将在 Figma 画框确认后补充。

## 5. 月末天数

统计口径改为过去的计划日期自动发生，不依赖人工确认。只计真实今天之前的日期，排除今天、未来和无计划日期，排除2月29日。

| 指标 | 计算 |
| --- | --- |
| 某事项天数 | 当月该事项已经过去的计划日期去重 |
| 某类型天数 | 同类型所有事项已发生日期并集 |
| 全月天数 | 所有类型已发生日期并集，不能直接相加 |

正计时从开始日起的过去自然日参与统计。已结束的事项只统计到结束日，结束日进入次日后计入，过去记录保留。倒数日按目标日或循环归零实例参与统计，提前显示倒数的日期不计入。点击合计进入日期明细，并可返回当天查看；取消后续计划不会删除过去的统计和日程。

## 6. 本版改动与已确认边界

已确认：纪念日计时、选中日计算、月末回退、仅跳过2月29日、三个作用范围、历史保留、类型锁定、自动发生、删除人工确认按钮。

AI只保留全局和单项开关，不增加分析、提醒或自动写入功能。农历和调休日历未接入。

未上线开发阶段，schema版本变化直接清除本应用旧版本数据并初始化，不清除工作台批注等无关数据。多个标签页编辑同一事项时提示关闭一个标签页后再继续；不同事项可以分别编辑。
