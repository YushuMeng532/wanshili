# 万事历 原型文档校验
版本：V0.5 · 确认日期：2026-11-19

关联：[PRD](./prd.md)、[开发说明](./dev-spec.md)、[页面设计](./page-design.md)、[原型](./prototype.md)、[验证记录](./validation.md)。

## 1. 校验对象

检查具名锚点是否有批注、批注是否指向现有章节、原型与文档是否可双向定位。正计时旧循环和结束条件锚点随字段删除，不计作缺失功能。

## 2. 问题分类

| 分类 | 含义 | 处理 |
| --- | --- | --- |
| 缺少说明 | 有锚点但没有有效章节说明 | 补充对应规则 |
| 章节失效 | 原章节已更名或移除 | 同步更新批注绑定 |
| 本页未出现 | 指定本页但锚点不存在 | 调整状态条件或清除旧绑定 |

## 3. 覆盖率口径

当前页面关联有效章节的锚点数除以具名锚点数。没有锚点显示不适用。覆盖率只衡量文档绑定，运行时业务验证见验证记录。
