# 万事历 原型文档校验
版本：V0.4 · 更新：2026-11-18

关联：[PRD](./prd.md)、[页面设计](./page-design.md)、[验证记录](./validation.md)。

## 1. 校验对象

检查当前网页原型的具名锚点是否有批注、批注是否能找到文档章节，以及章节定位是否能返回对应页面。工作台根据当前页面实时显示命中数量。

## 2. 问题分类

| 分类 | 含义 | 处理 |
| --- | --- | --- |
| 缺少说明 | 页面有锚点，未找到关联批注 | 补充动作、规则或状态说明 |
| 章节失效 | 批注引用的文档或章节已不存在 | 随文档修改更新绑定 |
| 本页未出现 | 批注指定本页，锚点未找到 | 检查元素改名、删除或状态条件 |

## 3. 覆盖率口径

当前页面已关联有效章节的锚点数 ÷ 当前页面具名锚点数。没有锚点时显示“不适用”；切换页面后重算。它衡量文档对应关系，业务验收结果见验证记录。
