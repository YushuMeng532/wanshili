# 万事历 MVP 页面设计
版本：V0.5 · 确认日期：2026-11-19

关联：[PRD](./prd.md)、[开发说明](./dev-spec.md)、[页面设计](./page-design.md)、[原型](./prototype.md)、[验证记录](./validation.md)。

## 1. 月历与当天事项

保留蓝粉绿、细线图标、开放列表、圆角与现有独立前端布局。桌面使用月历加侧栏列表；手机选日打开底部当天面板，关闭后选中日不变。

月历标记正计时开始日、已结束正计时的结束日、倒数日归零日和生日计划日。下方列表独立展示正计时累计和倒数天数。正计时开始日显示第1天，日期切换后数字随选中日变化。结束日显示「已结束 · 共 N 天」，次日不再显示这条事项。

## 2. 新建与循环

顶部返回、标题、取消；类型切换、名称、日期、AI开关、备注及底部保存沿用现有样式。正计时取消循环、结束条件和持续次数，只保留开始日期。倒数日保留循环和持续次数子层，生日每年重复。次数按有效计划出现次数计算，选择仅一次固定为1。

每周至少选一天；每月29/30/31不足时改月末，回退到2月29日则跳过；每年2月29日跳过。农历和工作日入口注明暂未接入。

子层完成只更新草稿，关闭不改变原值；主表单未保存不影响已保存事项。名称错误显示在字段下，其他内容保留，底部操作不遮挡长内容。

原结束条件画框改为纪念日规则说明，移出正计时操作连线；保留原画框ID便于追溯。

### 普通日程入口（待评审）

在「新建事项」页标题下方的类型栏加入「普通日程」，与正计时、倒数日、生日并列。预览将新按钮置于首位，采用两行两列布局，以适配 390 px 画框。打开表单时保留原来的默认类型。

选中「普通日程」后，依次显示名称、日期、循环、持续次数与备注，并沿用 AI 开关和底部保存操作。初始循环显示「仅一次」，持续次数显示「1 次」且不可改。改为循环后，可进入对应设置，关闭子层保留原值，主表单保存后生效。详情展示日期、循环、备注及日程状态。批注编号定位到新增按钮，并连接到 PRD「3. 新建与循环」。

## 3. 详情、编辑与删除

详情显示选中日计算结果与自动发生状态，移除已发生/未发生/未记录选择按钮。开始日第二天起，其他类型标签不可用，并显示类型锁定说明。

编辑与删除均提供仅这一次、这次及之后、整个系列，选中后通过明确确认按钮提交。过去的日程保留；过去选中日的单次操作不可用。删除确认使用粉色，与取消并列。

有未保存修改时使用居中确认：继续编辑或放弃修改。同事项在其他标签页编辑时显示冲突提示，要求关闭其中一个标签页后继续。

## 4. 状态与反馈

| 状态 | 展示 |
| --- | --- |
| 计划日期早于今天 | 已发生 · 历史日程已保留 |
| 今天或未来的计划日期 | 未到发生日，进入次日后自动计入 |
| 倒数展示日未归零 | 显示倒数，标明当天没有归零计划，不计入统计 |
| 名称未填 | 错误边框、请填写事项名称 |
| 保存中/失败 | 防重复提交；失败保留草稿和重试 |
| 取消后续计划 | 未来取消，历史可继续查看 |
| 调休日历/农历 | 明确未接入，不显示虚假的计算结果 |

## 5. 动效与操作尺寸

390×844事项画板等比缩放，延续原字体与按钮尺寸。主操作至少44×44；输入圆角12、卡片16、面板24。面板240ms滑入，遮罩渐显；未保存确认180ms淡入与96%到100%缩放。减少动态效果时取消位移动效。

## 6. 月度与扩展页面

统计显示事项、类型和全月过去计划日期的去重天数，点击可查看日期明细。今天及未来不计入；无历史显示0天。取消未来计划后，历史仍可通过统计明细访问。

AI仅保留设置开关；漏记询问、经期记录不进入本版已完成流程。工作台批注、规则说明与Figma图层文案同步使用V0.5口径。
