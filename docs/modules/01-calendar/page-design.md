# 万事历 MVP 页面设计
V0.2 · 2026-11-18

## 1. 页面与操作

| 页面 | 展示 | 动作 |
| --- | --- | --- |
| 日历主页 | 月份、日期、当天列表 | 切月、回今天、添加 |
| 事项创建 | 名称、类型、日期、循环 | 保存、返回；日期循环为子层 |
| 事项详情 | 配置、发生状态、备注 | 确认、编辑、删除 |
| 月度统计 | 每事项/类型天数、待确认日 | 切月、明细、修改 |

## 2. 状态与反馈

| 场景 | 行为 |
| --- | --- |
| 无事项 | 线性日历图形、文字及添加按钮 |
| 未记录 | 与未发生区分 |
| 读取中/失败 | 加载反馈/保留原内容并重试 |
| 名称空 | 字段下提示并聚焦 |
| 保存中/失败 | 禁止重复提交/保留输入重试 |
| 修改未保存 | 返回确认，可继续编辑 |
| 删除系列 | 选范围、解释影响、确认或取消 |
| 无发生记录 | 显示0天，引导开始记录 |

## 3. 视觉与操作

390×844移动端优先，冷白背景、开放列表、细线和留白。深蓝#54758A用于主操作，绿#AAB18D正计时、蓝#8FB2C9倒数日、粉#C8A0AD生日；文字或图标辅助颜色。

输入圆角12、卡片16、弹层24；主要触摸区至少44×44。长名称不遮挡操作，列表可滚动。按压约120ms、弹层约240ms；减少动态效果模式简化过渡。
