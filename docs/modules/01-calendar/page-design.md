# 万事历 MVP 页面设计
版本：V0.4 · 更新：2026-11-18

关联：[PRD](./prd.md)、[开发说明](./dev-spec.md)、[原型索引](./prototype.md)。沿用蓝粉绿、细线图标、开放列表与统一圆角，本版补齐02、03模块。

## 1. 月历与当天事项

顶部为品牌与月份导航，中部为周一开始的月历，底部为当天列表和新增入口。无事项显示线性日历图形、提示和添加按钮；有多项时按行展示名称、类型与日期信息。面板关闭后保留选中日。

## 2. 新建与循环

顶部返回、标题和取消；其下为正计时、倒数日、生日类型切换。主体依次为名称、日期、循环、结束条件、AI分析和备注，底部固定保存。

| 子层 | 内容与退出 |
| --- | --- |
| 日期 | 日期选择和确认，退出回原表单 |
| 循环 | 七种方式；每周、每月、每年进入各自配置 |
| 结束条件 | 不设结束或持续天数，仅正计时显示 |
| 生日历法 | 公历、农历切换，每年重复 |

名称为空时输入框标记错误，字段下提示；不挪走保存按钮。长内容滚动，固定操作不遮挡末项。

## 3. 详情、编辑与删除

详情顶部突出名称与类型，下面展示配置和当天确认；编辑、删除放在底部，内容与操作留出间距。编辑沿用创建表单并回填配置。

循环修改先打开作用范围面板，再保存。删除使用粉色确认按钮，与取消并列；确认后回当天列表并保留其他事项。未保存退出用居中确认框，主按钮“继续编辑”，次操作“放弃修改”。

## 4. 状态与反馈

| 场景 | 展示与行为 |
| --- | --- |
| 名称未填 | 错误边框和“请填写事项名称” |
| 保存中 | 按钮显示“保存中…”，阻止重复操作 |
| 保存成功 | 回当天列表，提示约1.5秒后整体消失 |
| 保存失败 | 提示失败、保留内容、提供重试 |
| 未记录 | 与已发生、未发生分别表达 |
| 统计无记录 | 显示0天并引导开始记录，待设计 |

## 5. 动效与操作尺寸

| 交互 | 本版配置 |
| --- | --- |
| 页面进入 | 240ms，Ease out |
| 底部面板 | 240ms，面板滑入、遮罩渐显 |
| 未保存确认 | 180ms，淡入及96%→100%缩放 |
| 类型切换 | 约200ms，保持表单位置连续 |
| 保存中示例 | 600ms后进入结果，成功提示停留1.5秒 |

新页面390×844，原四张月历保留现有尺寸。输入圆角12、卡片16、面板24；操作区域至少44×44。主色#54758A，正计时绿、倒数日蓝、生日粉，类型同时使用文字与图标。减少动态效果时使用短暂淡入；按钮按压反馈待配置。

## 6. 月度与扩展页面

月度统计需展示每事项、类型天数及日期明细，支持切月与修正原记录。经期记录、AI漏记询问和分析范围保留后续页面；当前不计为已完成原型。
