# 万事历｜月历与当天事项 页面设计说明

文档状态：草稿
版本：V0.1
对应需求：同目录 prd.md

## 1. 视觉方向

- 整体采用简洁、留白、细线条和圆角设计。
- 蓝色用于主要操作与选中状态。
- 浅绿、浅蓝、浅粉辅助区分事项类型。
- 状态同时使用文字或图标表达。
- 事项列表采用开放布局，减少卡片边框。

## 2. 页面对应关系

| 编号 | 页面 | 展示内容 |
|---|---|---|
| 01-01 | 月历·有记录 | 月历、日期状态、所选日期事项 |
| 01-02 | 月历·空态 | 月历、空态提示、新增入口 |
| 01-03 | 当天事项·多项 | 日期标题、多个事项、新增入口 |
| 01-04 | 当天事项·空态 | 日期标题、空态提示、新增入口 |

## 3. 月历交互

| 元素 | 操作 | 预期结果 |
|---|---|---|
| 上个月 | 点击 | 展示上一月份 |
| 下个月 | 点击 | 展示下一月份 |
| 今天 | 点击 | 返回当前月份并选中今天 |
| 日期 | 点击 | 选中日期，打开当天事项面板 |
| 新增入口 | 点击 | 进入新增事项流程，默认使用所选日期 |

日期显示规则：
- 一周从周一开始，至周日结束。
- 今天与选中日期应能分别识别。
- 有事项的日期显示事项标记。
- 标记数量及溢出形式待确认。

## 4. 当天事项面板

- 标题显示所选日期及星期。
- 有多个事项时展示事项列表。
- 事项展示名称、类型及对应天数信息。
- 关闭后返回月历，保留查看月份和选中日期。
- 列表超出可用高度时，允许纵向滚动。
- 多个事项的默认排序待确认。

## 5. 空态

- 使用细线条日历图形，搭配少量蓝粉绿点缀。
- 提示文字：这一天还没有事项。
- 提供明确的新增事项按钮。
- 空态图形不承担唯一的操作入口。

## 6. 加载与异常

以下为待实现的交互要求：

| 场景 | 展示及操作 |
|---|---|
| 数据读取中 | 展示加载提示，避免短暂显示无事项 |
| 数据读取失败 | 提示“读取失败，请重试”，提供重试入口 |
| 确实没有事项 | 展示正常空态 |
| 内容较长 | 避免文字遮挡日期、关闭按钮和主要操作 |

## 7. 动效与操作区域

- 面板打开和关闭采用轻缓过渡。
- 动效不阻挡连续操作。
- 主要触摸区域至少为44×44。
- 系统开启减少动态效果时，简化过渡。

## 8. 当前原型进度

- 已绘制4张首批界面。
- 已连接部分日期点击与面板关闭交互。
- 月份切换、新增入口及其余交互仍待补齐。
- 触摸区域与长列表场景仍待检查。
