## 1. 原型验证

### 月历

- [ ] 打开首页 → 默认展示当前月份。
- [ ] 查看星期栏 → 按周一至周日排列。
- [ ] 检查日期 → 当月天数与日期位置正确。
- [ ] 点击上个月 → 展示上一月份。
- [ ] 点击下个月 → 展示下一月份。
- [ ] 跨年切换月份 → 年份和月份同步变化。
- [ ] 点击今天 → 返回当前月份并选中今天。
- [ ] 查看今天和其他选中日期 → 两种状态可以区分。
- [ ] 查看有事项日期 → 能识别事项标记。

### 当天事项

- [ ] 点击日期 → 打开该日期的事项面板。
- [ ] 检查面板标题 → 日期和星期与所选日期一致。
- [ ] 当天有多个事项 → 展示该日全部事项。
- [ ] 查看事项 → 名称、类型和天数信息清楚。
- [ ] 关闭面板 → 保留原查看月份和选中日期。
- [ ] 列表超过面板高度 → 可以滚动查看全部内容。

### 空态与新增入口

- [ ] 点击无事项日期 → 展示空态图形和文字提示。
- [ ] 查看空态 → 显示明确的新增事项入口。
- [ ] 点击新增入口 → 进入新增事项流程。
- [ ] 检查新增流程 → 默认日期等于原选中日期。

### 视觉与操作

- [ ] 检查状态表达 → 除颜色外还有文字或图标辅助。
- [ ] 检查主要触摸区域 → 至少为44×44。
- [ ] 检查长名称 → 不遮挡关闭按钮和主要操作。
- [ ] 打开和关闭面板 → 过渡自然且不阻挡操作。

## 2. 开发后验证

以下项目需要在可运行产品中执行。

- [ ] 首次进入且没有数据 → 展示正常空态。
- [ ] 数据读取中 → 展示加载提示，避免闪现空态。
- [ ] 模拟读取失败 → 展示错误提示和重试入口。
- [ ] 点击重试且读取成功 → 恢复正常内容。
- [ ] 读取失败 → 已保存数据保持完整。
- [ ] 快速选择不同日期 → 最终展示最后选中日期的数据。
- [ ] 新增事项成功 → 对应日期标记和当天列表更新。
- [ ] 修改事项成功 → 月历和当天列表同步更新。
- [ ] 删除事项成功 → 月历和当天列表同步更新。
- [ ] 验证循环事项 → 在符合规则的日期出现。
- [ ] 刷新页面 → 已保存事项仍然存在。
- [ ] 手机上打开 → 文字和操作区域无明显溢出。
- [ ] 系统开启减少动态效果 → 页面简化过渡。
