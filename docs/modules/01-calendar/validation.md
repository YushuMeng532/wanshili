# 万事历 MVP 验证
V0.2 · 2026-11-18

## 1. 核心流程验收

- [ ] 打开 → 当前月和星期位置正确，周一为首。
- [ ] 切月再回今天 → 月份与选中日正确。
- [ ] 同日新增两项 → 均展示，默认日期正确。
- [ ] 切换三类型 → 对应字段，生日固定每年。
- [ ] 每周多选 → 仅指定日期出现计划。
- [ ] 工作日循环 → 调休日出现，法定休息日不出现，缺数据明确提示。
- [ ] 仅生成计划 → 实际发生天数仍为0。
- [ ] 同事项同日重复确认 → 只计1天。
- [ ] 同类型两事项同日 → 各事项1天，类型1天。
- [ ] 两类型同日 → 各类型1天，全月1天。
- [ ] 点击合计 → 定位计数日期及原记录。
- [ ] 改未发生或删记录 → 汇总同步减少。
- [ ] 循环编辑删除 → 确认范围；取消不变更。
- [ ] 保存失败 → 输入和旧数据保留，重试不重复。
- [ ] 刷新重开 → 原记录仍在。
- [ ] 未来或无计划日期 → 不列漏记。
- [ ] 390px长名称 → 不溢出，操作可达。

## 2. AI扩展验收

- [ ] 默认关闭 → 不分析。
- [ ] 单项排除 → 历史及未来内容均不参与。
- [ ] 拒绝建议 → 不修改原记录。
