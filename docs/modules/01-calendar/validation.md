# 万事历 MVP 验证记录
版本：V0.4 · 更新：2026-11-19

关联：[PRD](./prd.md)、[开发说明](./dev-spec.md)、[页面设计](./page-design.md)。

## 1. 2026-11-18：新建与名称校验

在Figma桌面版从月历空态点击“添加事项”，进入空表单；空名称保存后出现错误边框和“请填写事项名称”。点击名称区域进入预设“阅读”填写状态。已确认三个状态间的跳转与提示展示。

## 2. 2026-11-18：日期、保存与详情

正计时表单打开日期面板，确认后返回原表单；保存后进入当天三项列表，成功提示消失后整行点击可进入详情。已修复导入自动布局导致的面板错位、保存提示底色残留与事项行热区偏移。

## 3. 2026-11-18：编辑与未保存确认

详情进入编辑，取消后打开“放弃本次修改？”；选择继续编辑，预设配置保持显示。保存修改后展示作用范围面板，确认保存返回当天列表。详情底部内容与编辑按钮的重叠已修正。

## 4. 2026-11-18：删除与失败重试

从详情打开删除确认，确认后移除阅读，列表剩余考试、生日，共2项。独立“保存失败与重试”入口显示失败提示和保留内容，点击重试可回到当天列表。以上验证覆盖预设交互和视觉反馈。

## 5. 2026-11-18：工作台与文档对应

在桌面和390px手机视口分别执行43项浏览器检查。26个页面快照均可展示，具名锚点都有对应说明，跨页批注可定位到正确章节，章节复制正常，验证正文没有勾选框，详情内容未遮挡底部操作，页面无横向溢出。两组检查均通过。

## 8. 2026-11-19：画板比例与网页交互

对照Figma新建正计时表单的390 × 844画板、14px正文、18px标题及Noto Sans SC字体，修正字段收缩与字体回退。桌面和390px手机视口各48项浏览器检查通过，覆盖空名称校验、日期与星期保留、新建保存、详情、未保存确认、编辑范围入口、删除取消和确认，以及26个画板尺寸、字段无重叠和批注章节定位。真实浏览器截图已核对表单留白、按钮位置和字体。
