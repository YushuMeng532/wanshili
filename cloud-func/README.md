# 万事历 AI 中转 · 国内云函数部署手册

目标：把 AI 中转从 `vercel.app`（国内不可达）搬到国内云函数，用平台**默认域名**，不买域名、不备案。
部署完成后，页面仍留在 GitHub Pages（国内直连正常），AI 也能在国内网络下直连。

## 3. 部署方式 A：你在控制台点（推荐，不涉及给我密钥）

### 通用步骤

1. 进入函数计算控制台 → 新建函数
2. 运行环境：**Node.js 18 或 20**
3. 函数形态：**Web 函数**（不是事件函数）
4. 上传代码：把 `wanshili-ai-relay.zip` 直接上传（含 `scf_bootstrap`、`server.mjs`、`package.json`，无依赖，无需 `npm install`）
5. 启动命令：`node server.mjs`；若控制台没有「启动命令」字段，则包内的 `scf_bootstrap` 会兜底
6. 监听端口：`9000`
7. 内存 128MB，超时 30 秒
8. 环境变量按上表填
9. 保存并部署，拿到默认域名

### 腾讯云额外注意（重要）

- **优先用「函数 URL」，不要用 API 网关。**
  - 函数 URL 的域名是干净的根域名：`https://<app-id>-<url-id>.<region>.tencentscf.com`，路径直接透传到函数，`/api/plan` 就是 `/api/plan`。
  - API 网关默认域名带 `/release` 路径前缀，会导致前端请求 404。
- 部署后进入「触发管理」→「函数 URL」，**手动开启**（默认关闭），复制公网地址。
- `scf_bootstrap` 文件必须无扩展名、UTF-8 无 BOM、LF 行尾（Windows 打包已处理）。若平台报「scf_bootstrap 不可执行」，改用控制台的「启动命令」填 `node server.mjs` 即可绕开。

### 阿里云额外注意

- FC 3.0 选「Web 函数」+「HTTP 触发器」
- 触发器路径填 `/*`，认证方式选**无需认证**（否则前端请求会被网关拦掉）

## 4. 部署方式 B：我用 CLI 帮你部署

如果你希望我直接部署，需要你创建一个**最小权限**的临时子账号：

### 腾讯云

1. 访问「访问管理 CAM」→ 用户 → 新建子用户（编程访问）
2. 只勾选策略 `QcloudSCFFullAccess`（函数计算全读写）
3. 把 `SecretId` / `SecretKey` 给我
4. **部署完成后立刻禁用或删除该子用户**

### 阿里云

1. 访问「RAM 访问控制」→ 用户 → 新建 RAM 用户（OpenAPI 调用访问）
2. 只授予 `AliyunFCFullAccess`
3. 把 `AccessKeyId` / `AccessKeySecret` 给我
4. **部署完成后立刻禁用或删除**

> 这两个权限都只能在函数计算里操作，碰不到你的域名、账单和别的产品。但我仍然建议用完即删。

## 5. 部署后验收（我可以远程跑）

拿到域名后，我会执行 `verify-deployed.mjs`，检查：

1. `GET /health` → 200 且 `ready:true`
2. 错误 Origin 的 POST → 403
3. 正确 Origin 的 `POST /api/plan` → 200 且返回草稿

任何一项不过，就说明部署有问题，不用等前端改完才发现。

---

## 6. 切换前端（一行改动）

`assets/product-ai-config.js`：

```js
window.WANSHILI_AI_ENDPOINT = 'https://你的默认域名';
```

注意**只写到域名根**，不带路径。改完提交，GitHub Pages 部署后手机刷新即可。

---

## 7. 回滚

前端配置改回 `https://wanshili-ai-relay.vercel.app` 即可恢复原状，云函数可以留着不删（免费额度内不产生费用）。

## 8. 已知限制（写清楚，免得以后踩）

1. **限流与额度是进程内存态**。云函数多实例并发时，每个实例各自计数——实际上限会大于配置值。这是有意的取舍：省掉 Redis/数据库依赖。若要精确，需要接厂商的 KV 或数据库。
2. **单实例的 `/health` 里的 `dailyUsed` 只代表该实例**。
3. **默认域名可能被厂商限流或调整**，长期使用建议最终绑自有域名。
4. 本函数直接调用 DeepSeek，**Cloudflare Worker 与 Vercel 中转都可以下线**，但先别删，留作回滚。
